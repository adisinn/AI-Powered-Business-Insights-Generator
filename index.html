🚀 AI-Powered Business Insights Generator

Automated insight extraction using LLMs + Streamlit | A Final Year Student Project

The Challenge

Business analysts spend hours reading reports to extract actionable insights—a time-consuming, error-prone process.

Solution: Automate insight extraction using NLP and Large Language Models, then serve via a conversational dashboard.

✨ Key Features

📊 Data Ingestion

Load reports from CSV files or query data via SQL.

🧠 NLP Processing

Extract key sentences using keyword-based scoring (works offline).

⚡ LLM Integration

Call OpenAI APIs for smart insight generation or use rule-based fallback.

💬 Interactive Dashboard

Streamlit web app for uploading reports and exploring insights in real-time.

📈 Power BI Ready

Export insights and connect to Power BI for executive dashboards.

🧪 Tested & CI/CD

5 pytest tests + GitHub Actions workflow for continuous integration.

🚀 Quick Start (Windows PowerShell)

Step 1: Set up virtual environment

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Step 2: Configure API key (optional)

copy .env.example .env
# Edit .env and set OPENAI_API_KEY (or use rule-based fallback)

Step 3: Run the app

streamlit run app.py

Then open: http://localhost:8501
